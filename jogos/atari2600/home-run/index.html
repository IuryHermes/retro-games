Jogar Home Run Online - Atari 2600

Home Run é um jogo de esportes lançado em 1978 para Atari 2600. Desenvolvido por Bob Whitehead e publicado por Atari. O jogo adapta regras e fundamentos esportivos para partidas rápidas, com ênfase em posicionamento, tempo de comando e competição. Oferece suporte para até 2 jogadores.
